## 本 run 最大的产出：真跑技能全灭的根因（终评审日志重放）

**平台 `agent-evolve/skill_registry.py` 把所有技能 input_schema 硬编码成
`{doc_id, dpi}`** → 真 27b 忠实按 advertised schema 发参 → 149 次技能
调用 **0 次带 `value`**，技能子进程 120/120 全部失败。Fake 模型不看
schema 直发 `{"value": …}` → **419 测试全绿掩真跑全红**。

这改写了 V16/V17 的归因：V17 "wave2/3 回落 = currency 工具调用不稳"
实为 **schema 错配下技能从未生效**——回落的是无技能裸跑，不是
"技能在但用不对"。V18 修复：应用层重绑 schema 正确的描述符副本
（平台零侵入）+ 守卫测试（突变验证必红）。
